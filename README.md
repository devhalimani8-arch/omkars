# Omkar Nadar – Portfolio Website

A personal digital portfolio built with HTML, CSS, and JavaScript for the MITVPU BBA Module 5 Project Presentation assignment.

## 📁 File Structure
```
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── photo1.jpeg            ← Your profile photo (mirror selfie)
    ├── cert-best-player.jpeg  ← GLX Best Player certificate
    ├── cert-igl.jpeg          ← GLX Best IGL certificate
    └── cert-strategy.jpeg     ← Esports & Gaming Strategy certificate
```

## 🖼️ Rename Your Images Exactly Like This

| Your uploaded file | Save it as (inside assets/ folder) |
|---|---|
| Mirror selfie photo | `photo1.jpeg` |
| Best Player certificate | `cert-best-player.jpeg` |
| Best IGL certificate | `cert-igl.jpeg` |
| Esports Strategy certificate | `cert-strategy.jpeg` |

## 🚀 Deploy on GitHub Pages
1. Create a new GitHub repo (e.g. `portfolio`)
2. Upload all files keeping the folder structure above
3. Go to **Settings → Pages**
4. Set source to `main` branch, root `/`
5. Your site will be live at `https://yourusername.github.io/portfolio`

## ✅ Sections
- **Home** – Photo, name, tagline, hero badges
- **About** – Education, interests, goals, strengths
- **Achievements** – 3 GLX certificates + Design Thinking
- **Projects** – Leadership project, Marketing case study, Design Thinking, Strategy course
